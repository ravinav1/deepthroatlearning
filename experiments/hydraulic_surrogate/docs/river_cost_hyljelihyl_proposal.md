# Proposed continuous correction: Hyljelihyl routing and its supplied transfer cost

The strongest bounded next test is to separate the 0.26 Mm³ Hyljelihyl reservoir from the existing 307.26 Mm³ Vinje pool and restore its directed main river into Venemo. Compare a free-transfer version with the supplied convex marginal river cost. This adds one storage state and a short segment block; it does not require a seventeen-reservoir reconstruction. No candidate solver, target read, new optimization or learned model has been run for this review.

The blanket bypass/spill coefficients in the current LP are not an invented replacement for these four curves. The supplied bypass objects generally have `flow_cost_const: 10`, and the spill objects generally have `flow_cost_const: 1000`. The omission is that pooling removes the internal rivers entirely. In particular, applying the Hyljelihyl curve to every Vinje turbine or bypass flow would charge the wrong water and would not fix that omission.

The current [official river reference](https://docs.shop.sintef.energy/objects/river/river.html#flow-cost-curve) describes piecewise constant marginal flow costs, with the curve taking precedence over a constant cost. Its attributes use NOK/hour/(m³/s); the supplied competition price and water-value inputs use EUR/MWh. Our existing LP treats the supplied numerical costs in the same numeraire as those inputs. Preserve that explicit assumption to isolate this ablation; do not infer an exchange rate or tune a multiplier. `main_river` selects the path used for energy-value conversion, not a flow priority. A river without a maximum-flow input has no default maximum. These current documents explain mechanisms; they do not establish the competition's SHOP 17.17 commands.

The supplied YAML and the previously pinned public topology builder corroborate the step interpretation. The builder computes secant slopes of a total-cost function and writes those slopes into `flow_cost_curve`, then removes `max_flow_const` and `flow_cost_const`. Its archived source is `artifacts/source-dataset-audit-001/remote/create_final_topology.py`, function `apply_river_heuristics_in_yaml`. The supplied YAML, rather than a regenerated topology, remains authoritative.

The four tables have breakpoints `[0, 40, 100, 200, 400, 700, 1000]` m³/s and marginal coefficients `[1, 65, 239, 564, 1107, 1758, 1758]`. With hourly interval length one, introduce nonnegative segment flows `z[k,t]` in Mm³, widths `0.0036 * diff(breakpoints)`, and a final unbounded segment at the last slope. Then

```
river_volume[t] = sum_k z[k,t]
river_cost[t] = sum_k marginal_cost[k] * z[k,t] / 0.0036
```

The final repeated breakpoint is not a hard 1000 m³/s cap. Monotonically increasing costs make the LP load cheaper segments first; no binary segment selector is required. The objective subtracts this cost before the existing common monetary scaling. Do not interpolate the table values as total costs. For example, flow 40, 60 and 100 m³/s costs 40, 1340 and 3940 numerical currency units/hour respectively. The first and second marginal shadow-price wedges are 277.7778 and 18055.5556 numerical currency units/Mm³. For an interior transfer segment, the downstream minus upstream water shadow equals that segment's marginal cost; the usual bound complementarity applies at its endpoints.

The supplied connection chain is

```
Kjela turbine -> Hyljelihyl -> r_Hyljelihyl -> Venemo
Kjelavatn bypass/spill -> Hyljelihyl
Hyljelihyl -> b_Hyljelihyl -> Vinjevatn
Venemo <-> existing pooled Totak/Vaamarvatn approximation -> Vinje
```

Hyljelihyl has only 0.26 Mm³ of storage; the remaining Vaamarvatn/Totak/Venemo pool has 307.00 Mm³. Its small reservoir currently can borrow all pooled upstream storage without paying for or respecting the river direction. A 0.26 Mm³ buffer holds only 72.22 m³/s-hours. Even though Kjela's supplied turbine curve ends at 40 m³/s, local inflow and Kjelavatn bypass can push the river into its second marginal segment. This mechanism concerns transfer timing, short-buffer spill/bypass decisions and upstream water opportunity costs. It does not assert that a better physical optimum must match teacher commitments.

A read-only check used the unchanged saved continuous SHOP dispatch for the original twelve metadata-selected cases, all ending by 2021-01-01. Kjela discharge plus Kjelavatn bypass plus Hyljelihyl natural inflow exceeded 40 m³/s for 956 of 2016 hours. Five cases exceeded it for all 168 hours; the largest such known arrival was 62.94 m³/s. These are known arrivals under the saved dispatch, not reconstructed river flows or a proof that a newly optimized flow must cross that breakpoint. Storage, bypass and redispatch can change it. The evidence is `artifacts/river-cost-read-only-review-001/manifest.json`, SHA256 `d730c269f96b361cc2bad38e309e981af7e939f6ffea8603f831f8cfc923540f`; the script pins all twelve saved payloads and reads only topology, historical physical inputs and frozen metadata, with zero optimization calls and no target decoding.
