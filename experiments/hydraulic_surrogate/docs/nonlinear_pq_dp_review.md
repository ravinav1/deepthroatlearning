# Independent review of the nonlinear PQ switching proposal

Reviewed 2026-11-02 by the combined-export/review agent before implementation. The xgb_large agent owns the implementation and first 2021 experiment. No model fit or new cache was launched by this review.

The bounded experiment is approved: retain the exact 608-feature combined context/joint prefix, append six input-only columns (hourly optimal on-profit and 168-hour switching advantage for each of Haukeli, Lio and Hogga), and fit the three specialist models with the existing 350-tree, 31-leaf, learning-rate 0.06, deterministic 40% samples, seed 4173 and two threads. Use the same purged case IDs, saved sample arrays and full-hour validation. All six appended fields enter each specialist; other units' predictions stay unchanged.

This is distinct from the rejected `lgb-normalized-lp-switching-001`: that branch multiplied a best-conversion LP price margin by nominal Pmin/Pmax. Its scores were 0.9938401548990157 / 0.9934236209959993. The proposed feature instead maximizes actual unhulled nonlinear `price * P(q) - 0.0036 * q * (lambda_up - lambda_down)` over the physical on-domain at initial head, then applies the existing independently tested two-state switching DP. It does not repeat the rejected slower subset-hull joint LP benchmark or change any frozen LP model.

Implementation conditions:

- Read raw frozen LP-v1 duals in EUR/Mm3, known per-case hourly prices and initial reservoir state only. Use the 0.0036 discharge-to-hourly-volume conversion exactly once; normalize reward and DP advantage by `(1 + mean(abs(price))) * nominal Pmax` exactly once. Do not read target commitments, optimizer runtime, future realized storage or other cases' labels.
- Keep the original unhulled P(q) curve, efficiency breakpoints and exact Qmin/Qmax endpoints. Validate retained points against effective-head turbine lower bounds and generator Pmin/Pmax; explicitly fail and record an impossible on-domain. Preserve negative hourly on-profit. Off is a separate zero-profit DP state, so clipping on-profit at zero changes the optimization and is prohibited.
- Use supplied asymmetric startup/shutdown costs, free initial/final states and the complete known 168-hour case. This is an auxiliary feature; fixed water duals, initial head, omitted water reoptimization and Haukeli's approximate pooled topology remain limitations. It is not a feasible schedule or a reconstruction of unknown SHOP settings.
- Freeze exact source, data/cache hashes, six feature names, feature prefix, model settings, anchor and selection procedure before fitting. Synthetic tests must cover small-horizon brute-force DP equivalence, zero switching costs, negative on-profit/negative prices, normalization and dimensional units, exact feasible endpoints, input-only invariance and case order. Run a one-case timing/finite-output smoke before the 2021 fit.

The anchor is the current frozen four-component context/joint blend. Select one shared specialist replacement weight from `[0, 0.1, 0.25, 0.5]` on 2021 pooled micro AUC, with ties choosing the lower weight. At that same selected weight, build a matched control using the existing raw 608-feature component's three predictions; no control model retraining or separate control-weight search is needed. Require the new candidate to beat both the anchor and that same-weight control in 2021 before a separate 2022 fit, then apply the identical weight and acceptance conditions on 2022. This guards against attributing an improvement from reweighting the existing combined model to the new features. Apply the frozen Vinje projection after replacement.

Both years have already been reused for development and residual analysis. These checks are descriptive development evidence, not untouched confirmation. Neither the 0.998/both-years transfer condition nor the actual 0.999/top-three leaderboard objective can be established from this proposal.

The fixed50% specialist replacement passed2021: pooled AUC0.9949778297213558 versus anchor0.9949377186691472 and same-weight608control0.9949257714128659. Independent verification reproduced every grid score and exact selected-array bytes. Haukeli's raw unit AUC nevertheless declined from0.9696808063202165 to0.966003335746353; that counterexample was retained without changing unit weights.

The unchanged2022 candidate scored0.993683153449926 versus anchor0.9936914879536517 and matchedcontrol0.9936498343743312. It fails the anchor-improvement condition, so the branch is **rejected**. Independent proof is `artifacts/verify-nonlinear-pq-selection-2022-001/manifest.json`; the original2021 lock SHA remains `2853a50245e85e2fbf615f85b5ba93736018b6dd9c1cf6420411d0aa24b30a43`.
