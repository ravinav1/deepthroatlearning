# Pre-2021 pooled residual ranking screen

This experiment tests a global ranking correction to a **single 608-feature LightGBM anchor**, using genuine early forward out-of-fold predictions for all 14 generators. It does not reconstruct or establish an improvement to the accepted five-component GPU blend. Earlier CRF screening already used the Vinje subset of 2020, so this remains reused development evidence.

The fixed base-cache protocol is `docs/full14_early_oof_protocol.json`, SHA256 `58d98fe4d3f7ec3d7b0a102b6a0ca6a538790baaf11ddb0ef2d3677cefc96028`. The cache preserves nine Vinje models and fits 33 missing models under exactly the same six-day purge and 40% samples. Residual training uses 724 starts: all 365 in 2018 and 359 through 2019-12-25. Screening uses 360 starts from 2020-01-01 through 2020-12-25. Each forecast covers 168 hours and all 14 units. The completed cache must pass a separate independent audit before residual training; its actual manifest and audit SHA256 values are required explicitly on the command line.

All three learned arms use the identical 1,702,848 training output rows and 623 input columns: the existing 608 input-only features, 14 unit one-hot columns, and that output's raw unprojected OOF anchor logit. Base probabilities are clipped to [1e-6,1−1e-6] only when forming logits. No new target-derived feature, normalization, unit filtering, hyperparameter grid or early stopping is used. Output rows follow case, hour, unit order. A single binned training dataset is constructed with two threads; expanded float32 inputs occupy about 4.24 GB before bins and temporary workspace. This runs as one heavy local job after the OOF build finishes.

Each residual has 80 boosting rounds, maximum depth 4, at most 16 leaves, learning rate 0.03, L2=1, L1=0, minimum 100 rows per leaf, minimum leaf Hessian sum 0.001, column fraction 0.9, max bin 255, no row bagging, deterministic seed 4173 and two threads. These regularizers and sampling defaults follow the existing single608 recipe; only the prespecified shallow residual capacity changes. Fixed fit order is pairwise, ordinary BCE, then class-balanced BCE.

The pairwise arm minimizes RankNet logistic loss on fresh independent uniform positive and negative endpoints drawn from the entire pooled training population, with replacement. There are exactly 1,000,000 pairs per round, seeded by `SeedSequence([4173, round_index])`. It does not restrict queries to one case or unit and does not select only hard errors. Each round's draw hash and derivative summaries are retained. For N output rows and M pairs, the loss scale is `N/(2M) * sum(log(1+exp(s_negative−s_positive)))`. Reported loss per output is half the average pair loss. At zero margin, its expected row gradient and exact diagonal curvature match globally class-balanced sum BCE; ordinary BCE matches only when class counts are balanced. The class-balanced control uses fixed global row weights `N/(2N_positive)` and `N/(2N_negative)`, each determined solely from residual training labels.

The pair Hessian couples its two endpoints. The booster receives **twice the exact Hessian diagonal**, plus 1e-12, as a positive-semidefinite majorizer. It does not receive the full Hessian. Both BCE arms use their exact independent-row Hessians plus 1e-12. This fixed conservative optimizer therefore differs from BCE dynamics as well as the loss; the experiment does not isolate a pure causal effect of objective choice. Tiny exhaustive references and finite differences verify the exact gradient, full Hessian, majorizer, normalization and common-score-shift invariance. Global pairwise shift invariance does not imply the final sigmoid/projection is shift invariant; there is no offset, temperature or calibration search.

The anchor logit is supplied through LightGBM `init_score`; custom objectives assert that their first raw scores equal it exactly. Saved boosters predict only the learned residual, which is added back once. Zero residual uses an explicit identity branch returning original probability bytes, including dtype. Identity and all three learned arms receive the same single final Vinje order projection. All three trained models and traces are sealed before screen predictions; all screen prediction arrays are sealed before the new run decodes any 2020 target. Each saved booster must reproduce its screen residuals bitwise. Later targets are excluded by row selection before dtype decoding, verified with poisonous future-label fixtures.

Advancement requires all of the following on final projected probabilities: pairwise strictly beats identity, ordinary BCE and balanced BCE on the full year, and strictly beats identity separately on January–June and July–December through December25. A reduction in full-year `1−AUC` of at least 5% relative to identity is additionally reported as a **substantial gain** flag; smaller reproducible improvements may advance when the other gates pass. Root fixed this distinction before protocol freeze and before this run reads any screen labels. Raw AUC, log loss, every unit AUC and residual moments are descriptive only. A failed arm is not retuned on this screen. No 2021/2022 continuation, final fit, candidate submission or leaderboard selection is performed by this runner.

Implementation references: [LightGBM's custom objective interface](https://lightgbm.readthedocs.io/en/stable/_modules/lightgbm/engine.html) supplies raw scores and expects a gradient and Hessian vector; [XGBoost's learning-to-rank documentation](https://xgboost.readthedocs.io/en/stable/tutorials/learning_to_rank.html) describes unscaled pairwise RankNet loss. This implementation uses the former API with an explicit global pair sampler, not an NDCG objective or per-case ranking groups.
