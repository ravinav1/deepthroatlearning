# Read-only assessment: canonical pooled model

This is a distinct, feasible bounded hypothesis, not a trained candidate. No feature matrix, target array or model was built for this assessment. The completed river cache and running integer cache retain priority.

The rejected pooled experiment used 608 repeated case-hour features, 14 unit indicators and a frozen OOF base logit. It fit only 80 depth-4 residual trees on 2018/2019. Ordinary and balanced BCE residual standard deviations reached 8.31 and 43.92; the pairwise arm worsened 13 of 14 within-unit AUCs and lost to identity in both 2020 halves. That result rejects the particular residual recipe. It does not directly test a from-scratch classifier sharing an economically aligned representation across units. A new model must still acknowledge that the 2020 screen has been reused.

Canonicalization addresses a concrete representation problem: the same physical quantity currently occupies a different named column for each unit. A pooled learner over the wide table must first use unit identity to find its relevant flow, margin and storage columns. Remapping those quantities to common `own_*` columns lets the learner share economically meaningful thresholds directly. From-scratch unweighted BCE also starts without the nearly saturated base-logit offset that made the residual optimization unstable. Keep unit identity because teacher-specific behavior and generator operating ranges are not exchangeable.

The root proposal is a reasonable first fixed schema: 19 own-unit fields from LP3, joint-LP3, SHOP4 and LP-context9; 16 own-plant fields from physical6, LP4, joint-LP4 and normalized switching2; about 50 common calendar/normalized-price fields; unit/plant categorical identity and within-plant position/count; and the 14 global SHOP states plus nine global storage fills. About 112 columns is a planning estimate, to be replaced by an exact frozen mapping before any data build. The global physical state/storage block preserves cascade context that an own-unit-only table would discard. Every field can be remapped from the existing 664 columns; no new solver, target encoding or observed post-start storage is needed.

Unit and plant mapping must come from the frozen unit order/topology, never alphabetical assumptions. Preserve the existing normalized local water opportunity-cost convention: local shadow is upstream minus the appropriate downstream shadow, converted through that unit's own energy coefficient. Do not substitute another unit's conversion or reservoir index. The fixed `lp_*` and `shop_delta_*` columns already embody those distinctions. Plant siblings share reservoir fields but retain their own discharge/power ratios and unit identities.

Use the exact saved case-hour sample and include all 14 units for each sampled hour. The existing pre-2020 training sample contains 122,304 hours, or 1,712,256 long-form outputs. At 112 float32 columns the raw matrix is 767,090,688 bytes (0.714 GiB), compared with 3.974 GiB for 623 columns. The approximate 2021 sample of 146,899 hours would need 0.858 GiB at 112 columns. These are matrix sizes, not peak-RSS guarantees: feature construction, native bins, gradients and conversion copies add memory. Stream fixed row blocks into a numeric array, release the wide 664-column prefix, and predict in blocks before restoring exact case-hour-unit order and applying the unchanged Vinje projection.

A useful bounded comparison is 14 separate canonical 350-tree BCE models versus one fixed pooled 700-tree, 31-leaf BCE model, using the existing learning-rate 0.06/L2 1/sample/seed conventions. This is a proposed fixed capacity, not a sweep. Giving the pooled model 4,900 trees merely to match the sum of 14 independent tree counts would scan 14 times as many rows per tree and is not a fair compute match. Training time cannot be inferred reliably from raw matrix sizes; a small fixed timing check should precede a full screen after the current heavy slot is free.

The initial falsification can use all purged pre-2020 history and the already reused 2020 development year, with identical samples and labels in both canonical arms. Compare pooled against per-unit canonical models to expose negative transfer, then use a predeclared small convex blend grid against the saved original 608 anchor to test complementarity. Require useful projected pooled-AUC gains in the full screen and both fixed halves; no posthoc unit splice, label-derived feature selection or rescue calibration. Any advancement requires a separate frozen 2021 selection and locked 2022 confirmation.
